Почему useEffect запускается дважды?

Скорее всего, в приложении включён React Strict Mode. В режиме разработки React дополнительно запускает эффект и его очистку, чтобы обнаружить ошибки.

Добавь функцию очистки

Если эффект создаёт подписку, таймер или соединение, освобождай ресурс при очистке:

useEffect(() => {
  const connection = createConnection();
  connection.connect();

  // Вызывается при очистке эффекта
  return () => connection.disconnect();
}, []);

В production этой дополнительной проверки нет. Отключать Strict Mode ради неё обычно не нужно.
