Why does useEffect run twice?

Most likely, React Strict Mode is enabled. In development, React runs an extra effect and cleanup cycle to help reveal bugs.

Add a cleanup function

If the effect creates a subscription, timer, or connection, release it in the cleanup:

useEffect(() => {
  const connection = createConnection();
  connection.connect();

  // Called when the effect is cleaned up
  return () => connection.disconnect();
}, []);

That extra check doesn't happen in production. You usually don't need to disable Strict Mode because of it.
